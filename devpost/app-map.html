falsegreen: app map

A take-home guide to the code. It is a snapshot of the finished build and can drift; the source is the truth.

What it is

A CLI that breaks a good artifact on purpose and runs your guard on the broken copy. It has four pieces:

  • the guard runner, which runs your command and reads its exit code
  • twelve mutators, each of which breaks a file one specific way and can prove it did
  • the engine, which applies the baseline, bytes and self-test gates and then gives a verdict
  • the reporters, which produce the terminal table, JSON and Markdown output

One action, end to end

falsegreen run --guard "node verify.mjs {artifact}" --artifact report.json

Reference route (3 stops)

This is a reference route; it was not toured live. Search for the anchor names in your editor.

  1. src/cli.js, search for function cmdRun. This parses --guard and --artifact, picks the mutators, and wires the streaming terminal reporter to the engine's callbacks.
  2. src/engine.js, search for export function runEngine. This is the three gates: the baseline (Gate 1), after.equals(ctx.bytes) (Gate 2), and m.verify (Gate 3). Only after all three does a guard exit code become a verdict.
  3. src/mutators/placeholder-as-content.js, search for verify(ctx, m). This is a mutator proving its own work: placeholder text is present, the original text is gone, and the size is within ±15%.

A practice to reuse

Make the tool prove its own negative result before reporting yours

test/mutators.test.js hands each mutator's verify() the unmutated file and requires a rejection. That one test caught dead-regex trusting the list of patterns it had built, instead of reading the mutant back. This is the same "asks its own list" failure the tool hunts. On any project, wherever a component reports success, add a test that feeds it a case where nothing happened, and require that it does not report success.

Run it again

node --test                      # 43 tests
node bin/falsegreen.js bench     # naive 0/12 vs hardened 12/12
node examples/demo.mjs           # ~20 s scripted demo
